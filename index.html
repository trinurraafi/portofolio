DEVELOPER. SYSTEM THINKER. ALWAYS CURIOUS.

Curious mind.
Structured builder.

Gue tertarik pada titik temu antara logika sistem yang rapi dan tampilan antarmuka yang nyaman dipakai. Buat gue, bikin aplikasi web bukan cuma soal nulis baris kode, tapi gimana merancang alur data (mulai dari ERD, swimlane, sampai state machine) supaya masalah beneran selesai.

Fokus utama gue saat ini adalah pengembangan web dengan HTML, CSS, JavaScript, PHP, dan MySQL, sekaligus mengeksplorasi integrasi AI API dan pembuatan konten kreatif berbasis prompt engineering.
