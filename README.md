# Portofolio Tri Nur Raafi 🚀
*(Terinspirasi dari estetika & interaksi xaviera.dtechkit.my.id)*

Project ini dirancang khusus agar ringan, modular, dan siap langsung dibuka/diedit di **Antigravity IDE** atau kode editor favoritmu tanpa perlu install `node_modules` yang berat.

## 📂 Struktur Folder
```text
raafi-portfolio/
├── index.html              # Halaman utama (Hero, Selected Work, About, Playground, Contact)
├── README.md               # Dokumentasi & panduan kustomisasi
└── assets/
    ├── css/
    │   └── style.css       # Styling modern (Dark/Light mode, glassmorphism, animasi vinyl)
    ├── js/
    │   └── main.js         # Logika interaktif (Web Audio Synth, Modal Project, Token Estimator)
    └── img/
        ├── profile.jpg     # Foto profil asli Tri Nur Raafi
        ├── music-cover.jpg # Artwork pemutar musik (Sekian, Terima Kasih)
        └── glow.svg        # Efek dekorasi
```

## ✨ Fitur Utama
1. **Floating Navbar & Status Badge**: Lengkap dengan lokasi `KUNINGAN, ID`, foto profil avatar, indikator hijau *"Available for projects"*, dan tombol *switch* **Dark/Light Mode**.
2. **Hero Section & Animasi Teks**: Teks berganti otomatis (*Builds, Codes, Architects, Solves*).
3. **Interactive Vinyl Music Player (Tanpa MP3 Eksternal!)**: Menggunakan **Web Audio API Synthesizer** bawaan browser dengan piringan vinyl berputar berartwork kustom "Sekian, Terima Kasih" oleh Hindia!
4. **Selected Work + Pop-up Modal Interaktif**:
   - **SaranaCare**: Sistem Pengaduan Fasilitas Sekolah (dilengkapi simulasi *State Machine* tiket di dalam *pop-up*).
   - **SchoolFin**: Sistem Manajemen Keuangan & Pembayaran SPP Sekolah PHP & MySQL (dilengkapi *ledger* transaksi & jurnal otomatis).
   - **Nexora AI**: Modern AI Assistant berbasis Google Gemini API (dilengkapi live streaming token & Google Search grounding).
5. **Playground Widget (AI Token & Word Estimator)**: Alat hitung cepat jumlah kata, karakter, dan estimasi *token* LLM secara *real-time*.

## 🛠️ Cara Buka di Antigravity IDE
1. Buka folder `raafi-portfolio` di **Antigravity IDE**.
2. Jalankan `index.html` menggunakan **Live Server** atau buka langsung di browser.
3. Foto profil disimpan di `assets/img/profile.jpg` dan artwork musik di `assets/img/music-cover.jpg`.
